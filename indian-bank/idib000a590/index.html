How the code IDIB000A590 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00A590 is the part that names this branch.

The MICR code 221019009 is the number printed along the bottom of this branch's cheques. 221 is the city (the same three digits that begin the PIN code 221106), 019 is the bank and 009 is the branch.
