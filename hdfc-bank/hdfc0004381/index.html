How the code HDFC0004381 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 004381 is the part that names this branch.

The MICR code 243240503 is the number printed along the bottom of this branch's cheques. 243 is the city (the same three digits that begin the PIN code 243503), 240 is the bank and 503 is the branch.
