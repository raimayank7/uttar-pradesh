How the code HDFC0000655 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 000655 is the part that names this branch.

The MICR code 250240003 is the number printed along the bottom of this branch's cheques. 250 is the city, 240 is the bank and 003 is the branch.
