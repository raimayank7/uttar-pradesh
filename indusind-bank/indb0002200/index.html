How the code INDB0002200 is built

INDB is the bank part: the letters of Indusind Bank. The fifth character is always the digit 0. 002200 is the part that names this branch.

The MICR code 282234007 is the number printed along the bottom of this branch's cheques. 282 is the city (the same three digits that begin the PIN code 282005), 234 is the bank and 007 is the branch.
