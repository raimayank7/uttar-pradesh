How the code SBIN0017350 is built

SBIN is the bank part: the letters of State Bank of India. The fifth character is always the digit 0. 017350 is the part that names this branch.

The MICR code 271002055 is the number printed along the bottom of this branch's cheques. 271 is the city (the same three digits that begin the PIN code 271902), 002 is the bank and 055 is the branch.
